# diskctx

Context-aware disk failure prediction on public Backblaze Drive Stats.
Project context: `docs/HANDOFF.md`. Status: `PROGRESS.md`. Working rules: `CLAUDE.md`.

## Local setup

```
python3 -m venv .venv
.venv/bin/pip install -e ".[dev]"
.venv/bin/pytest -q
```

The Colab notebook (`notebooks/diskctx_colab.ipynb`) is generated by `tools/build_notebook.py` (from M6).
